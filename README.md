# 🧮 CALCMASTER 3000

## 📝 Sobre o Projeto
O **CALCMASTER 3000** é uma calculadora robusta desenvolvida em **Java**, projetada para rodar diretamente no terminal (Console).

O diferencial deste projeto é a interface visual desenhada em ASCII e a implementação de um loop de execução contínuo, permitindo realizar múltiplos cálculos sem precisar reiniciar o programa.

## 🚀 Funcionalidades
O sistema suporta operações matemáticas fundamentais e avançadas:

* **➕ Adição**
* **➖ Subtração**
* **✖️ Multiplicação**
* **➗ Divisão**
* **📈 Potenciação (`^`)**: Utilizando a biblioteca `Math.pow`.
* **✔️ Raiz Quadrada (`√`)**: Utilizando a biblioteca `Math.sqrt`.
